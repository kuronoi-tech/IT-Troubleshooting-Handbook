# Scenario 02: Computer Cannot Connect to Wi-Fi

**Category:** Networking  
**Operating System:** Windows  
**Author:** kuronoi  
**Status:** Completed (Simulated Training Case Study)

## 1. Problem Description

A Windows laptop was unable to connect to an available Wi-Fi network, although other devices at the same location could connect successfully.

The objective was to identify the possible cause and restore wireless connectivity.

## 2. Possible Causes

- Airplane Mode was enabled.
- Wi-Fi was disabled.
- Incorrect Wi-Fi password.
- Corrupted or outdated saved network profile.
- Wireless network adapter was disabled.
- Faulty or outdated wireless network driver.
- Wireless adapter hardware problem.

## 3. Investigation and Diagnosis

The following troubleshooting steps were performed in the simulated scenario:

1. Checked that Airplane Mode was OFF and Wi-Fi was enabled.
2. Confirmed that the laptop could detect the Wi-Fi network.
3. Verified that the correct Wi-Fi password was being used.
4. Forgot the saved Wi-Fi network and attempted a fresh connection.
5. Opened Device Manager and inspected the wireless network adapter.
6. Identified a yellow warning triangle on the wireless adapter.
7. Opened the adapter properties and checked Device Status.
8. Windows reported Code 10: "This device cannot start."

## 4. Troubleshooting Procedure

The following actions were selected:

1. Confirmed the basic wireless settings.
2. Checked the saved Wi-Fi connection details.
3. Reconnected to the network using the correct password.
4. Inspected the wireless adapter through Device Manager.
5. Investigated the reported device error.
6. Selected a wireless driver update using a trusted manufacturer source or Windows Update.
7. Restarted the laptop after the simulated driver update.

## 5. Solution Implemented

In the simulated case, updating the wireless network adapter driver resolved the connection problem.

The laptop successfully reconnected to the Wi-Fi network after restarting.

## 6. Results and Verification

The following verification checks were completed in the simulated scenario:

- Confirmed that the laptop connected to the Wi-Fi network.
- Confirmed that internet access was available.
- Checked that the connection remained stable.
- Confirmed that the reported problem was resolved.

**Result:** Successful restoration of wireless connectivity in the simulated training scenario.

## 7. Lessons Learned

- Begin troubleshooting with simple checks before attempting advanced repairs.
- Incorrect passwords and outdated network profiles can prevent Wi-Fi connections.
- Device Manager helps identify network adapter and driver problems.
- Error codes provide useful information during diagnosis.
- Driver updates can resolve certain network adapter problems.
- Always test the connection after implementing a solution.
- Proper documentation helps other technicians understand previous troubleshooting work.

## 8. Tools and Technologies

This case study demonstrated a systematic approach to troubleshooting a Windows laptop that could not connect to Wi-Fi.

The exercise improved understanding of wireless connectivity, network adapter diagnosis, driver troubleshooting, verification and IT support documentation.
